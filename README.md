# AYSTO

Website for [AYSTO](https://aystoai.com), an AI automation and web studio in London run by Samuel Ayo.

AYSTO builds websites, AI receptionists, chatbots and booking automations for owner-run UK businesses, starting with private clinics (dental, aesthetics, physio).

## What's on the site

- Clinic-focused homepage with a live AI voice receptionist demo
- `/business` page for local businesses: free homepage mockup before you pay, live in 7 days
- Blog and booking call flow

## Stack

Static HTML, CSS and vanilla JavaScript. No build step. Hosted on Netlify, domain on GoDaddy.

## Deploy

This repo is connected to Netlify. Every push to `main` redeploys aystoai.com.
